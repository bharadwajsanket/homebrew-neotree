# homebrew-neotree

Homebrew tap for [neotree](https://github.com/bharadwajsanket/neotree) — a fast, minimal, developer-focused directory tree CLI written in C.

## Install

```bash
brew tap bharadwajsanket/neotree
brew install neotree
```

## Verify

```bash
neotree --version
neotree --help
```

## Update

```bash
brew update
brew upgrade neotree
```

## Uninstall

```bash
brew uninstall neotree
brew untap bharadwajsanket/neotree
```
